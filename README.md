# Lobster Platform Overview

Interactive page presenting the Lobster differentiators (FR / EN): eight tiles, each with an explanation and a short demo, plus a product roadmap section.

## Run it

Open `index.html` in Chrome or Edge. No server or build step is needed. Keep the `assets/` folder next to it.

## Content notes

- Language: French and English, switch in the header.
- Roadmap content is a selection from Lobster's public product roadmap (lobstersoftware.com), checked 17 Nov 2026.
- Screenshots have personal data and customer names masked where needed.
- Fonts: Dax Pro (Lobster brand font) and Roboto, logo files from the Lobster CI.
